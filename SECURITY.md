# Security Policy

## Repository scope

This is a curated portfolio repository for the CashierNow website. It contains documentation, production screenshots, and small sanitized examples for professional evaluation.

- No production credentials, tokens, certificates, environment files, or deployment keys are included.
- No production backend, database, authentication system, API implementation, or administrative interface is included.
- No deployment configuration or private infrastructure details are included.
- The complete production implementation is maintained privately and is intentionally not distributed here.
- Public code samples are simplified portfolio-only examples and are not the production application.

The live website at [cashiernow.online](https://cashiernow.online) is operated independently. This repository grants no access to or authority over production systems.

## Reporting a security issue

Please report suspected security issues privately:

- Open a [GitHub Security Advisory](../../security/advisories/new), or
- Contact the maintainer through the channels listed on the [GitHub profile](https://github.com/ahmedsalahma).

Do not open a public issue containing vulnerability details, credentials, or sensitive reproduction information. Please allow time for investigation and remediation before public disclosure.

## Production security note

The production website uses defense-in-depth browser controls, including a nonce-based Content Security Policy and standard defensive response headers. Exact deployment and infrastructure configuration is intentionally outside the scope of this public portfolio.
