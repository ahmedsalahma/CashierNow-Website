# CashierNow Design System Notes

These notes document the thinking behind the production visual system without publishing its complete tokens or implementation.

## Foundations

- **Typography:** Cairo variable font for cohesive Arabic and Latin rendering.
- **Direction:** RTL is the default content direction; numerical and technical islands opt into LTR explicitly.
- **Color:** restrained neutral surfaces with semantic foreground, muted, border, and emphasis roles across light and dark modes.
- **Spacing:** consistent section rhythm and an 8px-grid sensibility.
- **Shape:** rounded cards and controls establish a coherent product language.

## Components

- Primary and secondary actions communicate conversion hierarchy.
- Pricing cards preserve alignment as values change across billing periods.
- Selected states combine color, border, and semantic attributes rather than relying on motion alone.
- Demo surfaces intentionally separate product context from the marketing shell.

## Interaction principles

- Motion explains state changes and navigation continuity.
- Keyboard focus remains visible.
- Reduced information density and vertical stacking support narrow screens.
- Decorative effects are hidden from assistive technology.

Exact tokens, production assets, and proprietary component code are intentionally omitted.
